Shaft Torsion Toolkit

User manual and technical reference. From a STEP model of a shaft to a lumped torsional vibration model: section inertias, FEM torsional stiffness, natural frequencies, time response, frequency response and animation on the CAD model.

Version 1.0.0Python 3.10+Units: SI internally, mm for lengths in inputs

1 Overview

The toolkit takes a shaft from a STEP file and turns it into a chain of rotating inertias connected by torsional springs. Each step feeds the next:

1 · Split & inertiaCut the CAD model with planes normal to the axis and compute each section's mass moment of inertia Ji.
2 · FEM stiffnessMesh with tetrahedra, clamp one end, twist the other, read the rotation in each section and derive springs ki.
3 · Vibration modelSolve J θ̈ + C θ̇ + K θ = M(t): natural frequencies, mode shapes, time simulation, FRF.
4 · AnimationShow the time response, a mode shape or the static FEM twist on the split CAD model; export GIF/MP4.

2 Installation

Windows

  1. Install Python 3.10 or newer (64-bit).
  2. Run setup_venv.bat once. It creates .venv and installs requirements.txt.
  3. Start the GUI with run_gui.bat. You can drag a .step file or a project .json onto it, or pass it as an argument.

Any operating system

python -m venv .venv
. .venv/bin/activate              # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python run_gui.py examples/stepped_shaft_project.json

Linux: gmsh needs a few system libraries, at least libGLU: apt install libglu1-mesa. On a headless machine you may also need libxcursor1 libxft2 libxinerama1.

3 Quick start

  1. Open examples/stepped_shaft.step with Open STEP file. The axis is found automatically.
  2. Cut planes: type positions in mm (e.g. 60, 140, 220, 320, 450, 540) or use Equal sections. Click Split model & compute inertias.
  3. FEM stiffness tab: keep the defaults (steel, quadratic tetrahedra, start end clamped) and run. Expect one to a few minutes for ~30 000 elements without PARDISO.
  4. Vibration model tab: click Build model, add damping, then compute modes. Add loads and run a simulation or an FRF.
  5. Animation tab: pick a mode or the simulation, press play, export to GIF.
  6. File → Save project to store everything in a .json.

Or load examples/stepped_shaft_project.json, which already contains cuts, material, loads and FRF settings. examples/gear_shaft_project.json is a more realistic case: a gearbox output shaft with a gear bonded on a feather key, keyways, grooves and fillets (1st natural frequency ≈ 394 Hz when grounded at the clamp).

4 GUI reference

Long computations (split, FEM) run in a background thread; progress messages appear in the status bar.

4.1 Tab 1 — Geometry

  • Open STEP file. Assemblies with several solids work. Touching solids are fused at their contact faces (bonded contact).
  • Shaft axis.
    • auto (default): the principal axis of inertia that differs from the other two (see 5.1). Within 1° of X, Y or Z it snaps to that axis.
    • X / Y / Z: global direction through the centre of mass.
    • custom: origin [mm] and direction vector.
  • Cut planes. Positions in mm measured from the shaft start along the axis. Type them, use Equal sections, or enable Pick and right-click on the model. Planes are previewed in red. Sort, Remove and Clear manage the list.
  • Split model & compute inertias produces a table with start, end, mass and J [kg·m²] per section; each section gets its own colour in the 3D view. View along axis aligns the camera.

4.2 Tab 2 — FEM stiffness

SettingDefaultMeaning
E, ν210 GPa, 0.3Isotropic linear-elastic material. G = E / (2(1+ν)).
Torque1000 N·mTorque on the loaded end. The model is linear, so it only scales the angles; stiffness is independent of it.
Fixed endstartEnd that is clamped (all DOFs zero). The other end is twisted through a rigid coupling (RBE2-like).
Element sizeautoauto = min(L/40, rmin/2): at least ~4 elements across the thinnest section.
Element typequadraticQuadratic tetrahedra (tet10) are recommended. Linear tetrahedra (tet4) are 10–15 % too stiff in torsion.

Lumped inertia atmiddleWhere each section's rotation is measured: geometric middle of the section, or its centre of mass.

The result table lists, per section: the rotation θ at the lumped position, the spring to the next inertia, and the section's own stiffness between its cut planes. Below it: the clamp-to-nearest-inertia stiffness and the total stiffness. The 3D view can show the FEM rotation field on the mesh.

4.3 Tab 3 — Vibration model

  • Build model fills the tables from steps 1 and 2. J, k and c are editable, so you can add attached parts (hubs, gears), a coupling stiffness, or values from other sources.
  • Damping
    • a damper c per spring (between inertias),
    • damping to ground per inertia (bearings, fluid),
    • c = β·k — stiffness-proportional damping for all springs,
    • c for ζ at the 1st elastic mode — picks β so that the first elastic mode gets the damping ratio ζ.
  • Boundary condition: free–free, or grounded at the FEM clamp. Grounded adds the clamp spring kground (from the FEM) and an optional damper cground on the inertia next to the clamp.
  • Modes: undamped natural frequencies, mode shapes (normalised to max |φ| = 1) and modal damping ratios.
  • Loads — torque on inertia # (1-based in the GUI): constant, step, ramp, pulse, sine (offset, phase), linear sweep, or a formula in t. See 5.6.
  • Simulation: end time and Δt. Δt = 0 selects 20 steps per period of the highest mode.
  • Plots: angles, twist, spring torques, speeds, loads, and the receptance FRF (rotation per unit torque) for a chosen excitation inertia and frequency range.

4.4 Tab 4 — Animation

  • Source: time simulation, a mode shape, or the static FEM rotation.
  • Display: rigid sections — each CAD section turns with its inertia; smooth twist — the rotation is interpolated along the axis.
  • Colouring: by true rotation angle or by section. Pointers show the rotation of each section.
  • Amplification: automatic (largest shown rotation 20°) or manual.
  • Export: GIF (needs imageio) or MP4 (needs imageio-ffmpeg).

4.5 File menu

  • Save / Load project (.json): STEP path (stored relative to the project file), axis, cuts, material, FEM settings, model values and loads. Results are recomputed after loading.
  • Export results to a folder as ;-separated CSV (see 8).
  • Save screenshot of the 3D view.

5 Theory

All internal quantities are SI: m, kg, s, N, rad. Positions s are measured along the shaft axis.

5.1 Shaft axis

For a body of revolution two principal moments of inertia are equal; the third belongs to the axis. The automatic mode computes the inertia tensor of the whole model about its centre of mass and picks the principal direction whose moment is farthest from the mean of the other two, penalising pairs that are not equal. This works for long shafts and short discs alike. If the axis is within 1° of a global axis it snaps to it, and the sign is chosen so the dominant component is positive.

5.2 Section inertias

The model is split with planes normal to the axis (OpenCASCADE boolean fragments). For each section, gmsh/OCC gives volume, centre of mass and inertia tensor Icom. With density ρ, mass m = ρ·V and the moment about the shaft axis (unit vector a through point p) follows from the parallel-axis theorem:

J = ρ · ( aT Icom a + V · d² ), d = distance of the section's centre of mass from the axis

Check: a solid cylinder of diameter D and length L gives J = ρ·π·D⁴·L/32.

5.3 FEM model

  • The split model is meshed with linear or quadratic tetrahedra; cut faces are shared, so the mesh is conforming across sections.
  • Isotropic linear elasticity, small strains; stiffness matrix assembled in chunks of 8000 elements.
  • Clamp: all nodes within the end band of the fixed end have zero displacement.
  • Load: all nodes of the loaded end get a rigid small rotation φ₀ about the axis (prescribed displacement u = φ₀·r·t, t = tangential unit vector). The reaction torque Tref on that face is computed from the nodal forces, and the solution is scaled by T/Tref.
  • Solver: PARDISO (pypardiso) if installed; otherwise, for more than 30 000 unknowns, smoothed-aggregation AMG-preconditioned CG (pyamg, rigid-body modes as near-null space); otherwise SuperLU.

5.4 Stiffness extraction

The rotation θ at an axial position s₀ is the least-squares rigid rotation of all nodes in a thin slice |s − s₀| ≤ band (band = 0.6 element sizes, widened automatically until at least 12 nodes are found). A linear variation along the slice is allowed:

ut = r · ( θ + θ′ · (s − s₀) ) → least squares for θ, θ′

From these rotations, with the applied torque T:

QuantityFormulaMeaning
ki (spring)T / |θmid,i+1 − θmid,i|Spring between inertia i and i+1 — used in the vibration model.
ksection,iT / |θcut,i+1 − θcut,i|Stiffness of the section between its own cut planes.
kgroundT / |θmid of the inertia next to the clamp|Clamp → nearest inertia; used for the grounded boundary condition.
ktotalT / θloaded endWhole shaft, clamp to loaded end.

Because springs are measured between section middles, the 3D stress field around shoulders and fillets is part of the FEM solution, so local stiffening or softening at diameter steps ends up in the spring values.

5.5 Vibration model

J θ̈ + C θ̇ + K θ = M(t)
  • J = diag(J₁ … Jn).
  • K, C: tridiagonal chain assembled from ki, ci; C also gets the damping to ground cabs,i on the diagonal; the grounded inertia gets kground, cground.
  • Modes: generalised eigenproblem Kφ = ω²Jφ. Modal damping ratio ζj = φjTCφj / (2 mj ωj) (diagonal of the modal damping matrix). Exact damped eigenvalues are available via complex_modes().
  • Time integration: Newmark, average acceleration (β = ¼, γ = ½): unconditionally stable, no numerical damping. The effective matrix is LU-factorised once.
  • Spring torque between i and i+1: ki(θi+1 − θi) + ci(θ̇i+1 − θ̇i).
  • FRF (receptance): Θ(ω) = (K − ω²J + iωC)⁻¹ enode, in rad per N·m.

Without any damping, the simulated response rings forever and spring torques show every mode at full amplitude. Add at least a small ζ (e.g. 1–2 %) for realistic time histories.

6 Batch mode (no GUI)

python -m shaft_torsion.cli project.json [output_folder]

Runs split → FEM → vibration model → time simulation (if loads are defined), prints a summary table and natural frequencies, and writes CSV files, split_model.brep and time_response.png. Without an output folder, results go to <project>_results/.

In batch mode, when "model" is null, the model is grounded at the FEM clamp and has no damping.

10 Python API

All steps are usable from scripts. Minimal example:

from shaft_torsion import geometry as g
from shaft_torsion.fem import FemSettings, run_torsion
from shaft_torsion.dynamics import Load
from shaft_torsion.project import model_from_results

info  = g.load_step("examples/stepped_shaft.step")
axis  = info.auto_axis                                   # or g.Axis(origin_m, direction)
s0, s1 = g.axial_range(info.surface[0], axis)
cuts  = [s0 + x / 1000 for x in (60, 140, 220, 320, 450, 540)]
geo   = g.split_model("examples/stepped_shaft.step", axis, cuts, 7850.0, (s0, s1))

res   = run_torsion(geo, FemSettings(E=210e9, nu=0.3, order=2))
model = model_from_results(geo, res)                     # grounded at the clamp
model.c = 1e-5 * model.k                                 # c = beta * k

f, phi, zeta = model.modes()
sim = model.simulate([Load(node=6, kind="step", amplitude=200, t_start=0.005)],
                     t_end=0.1, dt=model.recommended_dt())
H = model.frf(node=6, freqs=[10, 100, 1000])

11 Verification

Run python -m pytest tests -q. The tests compare with closed-form results:

  • Section inertias of a Ø40 mm cylinder along an oblique axis vs. ρ·π·d⁴·L/32 — relative error < 1e-6.
  • FEM stiffness (between inertias, per section, clamp → inertia, total) vs. G·Ip/L — within 0.2 %; with a 6 mm mesh the error is about 0.001 %.
  • Two-inertia natural frequency, the step response of a single grounded inertia, and the damping ratio.

12 Limits & tips

  • Linear-elastic, small-strain, one isotropic material. For parts of other materials, edit J and k in the vibration-model tables.
  • Cut planes are always normal to the shaft axis; positions are measured along it.
  • The rigid coupling at the loaded end blocks warping of that face. This matters only for non-circular end sections; springs are measured between section middles, away from the ends.
  • Keyways, splines and fits are modelled exactly as in the CAD; touching solids are bonded; simplify the CAD if local features should not stiffen the shaft.
  • Large meshes: install pypardiso (much faster). Without it, AMG-CG (pyamg) is used, then SuperLU. Memory grows quickly with element count; coarsen the mesh first, then refine to check convergence.
  • Use quadratic elements. If you must use linear tetrahedra, expect 10–15 % too high stiffness.
  • Error “Too few nodes on the shaft end faces”: increase the end-face band.
